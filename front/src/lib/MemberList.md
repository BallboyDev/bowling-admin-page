# MemberList.svelte 파일 수정 계획
- MemberList.svelte 파일은 볼링 동호회의 회원리스트를 관리하기 위한 페이지로 기본적인 회원 등록, 수정, 삭제 등의 기능을 제공한다.

## 1차 개선
- 수정된 내용은 동일한 경로의 MemberList_temp.svelte 파일로 복사(백업) 한후 적용

### 기능
1. 현재 구현된 기능은 모두 동일하게 구현
1. 기존 사용하는 API는 모두 그대로 사용
1. 추가적으로 필요하다고 생각되는 기능이 있다면 1차 수정후 정리하여 제안해줘

### 디자인
1. 모바일에서 시인성이 좋아지는 방향으로 개선을 진행한다.
1. 현재 프로젝트의 기본적인 색체는 유지한다.
1. 화면 디자인은 모바일 화면 기준을 우선시한다.
1. sveltestrap 라이브러리와 'front/template/css.css'코드를 기반으로 디자인을 하며 상세 내용은 아래를 따른다.
    - css 코드는 최소한으로 작성한다.
    - px단위가 필수가 아닌 부분은 rem 단위로 변환하고 가능한 0.25 단위로 변경해줘
    - 디자인에 필수적인 부분이 아닌 사이즈 값은 css.css에 있는 스타일로 변경하거나 기본값을 사용해줘
    - 태그의 class 가 길어지더라도 가능한 css 코드는 줄여줘
    - css 코드가 필수적인 부분은 가능한 태그내의 style=""로 변경해줘
    - 하나의 css 블럭보다는 여러개의 class 값으로 만들어줘
    - 가능하다면 <style> 태그의 내용은 50줄 이하로 줄여줘

## 2차 개선
- 1차 개선 내용을 기반으로 2차 개선 내용을 작업

### 기능
1. 목록 상단에 검색창을 두고 이름을 입력시 필터링하는 기능 추가

### 디자인
1. 회원 카드에서 회원 가입 일자 데이터(API 추가 예정)만 표시하고 나머지 데이터는 모두 제외
1. 이름을 눌러야 정보 수정 모달이 생성되는 방향을 명확하게 알아보기 쉽게 수정
1. 함께 연계되어 있는 모달들의 디자인도 1차 개선사항과 동일한 방향으로 디자인을 수정한다.


## 3차 개선

### 디자인
1. 가입일자는 members API에서 조회된 joinDate 데이터를 표시하도록 수정
1. 이름을 선택시 수정 모달 대신 선택된 회원의 상세 정보를 제공하도록 수정
1. 상세 정보 모달에서 수정 버튼 선택시 수정 기능 활성화
    - 가능하면 새로운 모달을 만들기 보다는 상세 정보 모달을 활용하는 방안으로 개선
1. 상세 정보에는 이름, 권한, 전화번호, 핸디캡, 스타일, 생일, 등급을 표현

## 4차 개선

### 기능
1. 회원정보 수정 모달에서 핸디캡과 등급도 수정 할 수 있도록 수정해줘
    - 아직 API가 수정 되어 있지 않으니 다른 데이터와 수정 방법이 동일하게 작업해줘

1. 회원등록 모달도 수정 모달과 동일하게 핸디캡과 등급에 대한 입력 칸도 만들어줘

### 디자인
1. 탈퇴 버튼의 활성과 표시를 수정 상태에서 상세 정보 표시 상태로 옮겨줘
1. 탈퇴 버튼을 누르면 다시한번 확인을 위한 단계를 넣어줘
1. 회원 ID가 10000이상인 경우 회원 이름 옆에 'GUEST' 라는 표시를 해줘


## 5차 개선은 다음 순서를 제안합니다.
1. 저장 결과 동기화: API 수정 후 서버 값을 다시 조회하여 실제 저장 결과 표시.
2. 수정 내용 보호: 변경된 항목이 있을 때만 저장 활성화, 저장하지 않고 닫을 때 확인.
3. 입력 검증 개선: 연락처·생일 형식과 핸디캡 허용 범위를 정하고 항목별 오류 표시.
4. 목록 탐색 개선: 회원·게스트 및 등급 필터, 이름·가입일 정렬 추가.
5. 모바일·접근성 점검: 작은 화면, 키보드 탐색, 탈퇴 확인 단계의 초점 이동 검증.
