# PersonalRecord.svelte 파일 수정 계획
- PersonalRecord.svelte 파일은 볼링 동호회에서 정기전 진행 후 점수 기록과 기타 진행을 위한 페이지 이다.

## 1차 개선
- 현재 페이지에서 필요로 하는 관련 API가 아직 구현이 되어 있지 않아 필요한 API는 필요한 위치에 API 명세를 작성한다.

### 기능
1. 회원의 개인 기록을 확인할 수 있다.
1. 기본적으로 2026년 기록만을 확인하지만 기간 선택을 하여 특정 기간내의 기록만을 확인할 수도 있다.
1. 정기전 뿐만 아니라 회원이 개인적으로 진행한 게임의 점수를 입력할 수 있는 모달을 띄우기 위한 버튼을 넣는다.
    - 모달은 아직 제작하지 않는다.


### 디자인
1. 모바일에서 시인성이 좋아지는 방향으로 개선을 진행한다.
1. 현재 프로젝트의 기본적인 색체는 유지한다.
1. 화면 디자인은 모바일 화면 기준을 우선시한다.
1. sveltestrap 라이브러리와 'front/template/css.css'코드를 기반으로 디자인을 하며 상세 내용은 아래를 따른다.
    - css 코드는 최소한으로 작성한다.
    - px단위가 필수가 아닌 부분은 rem 단위로 변환하고 가능한 0.25 단위로 변경해줘
    - 디자인에 필수적인 부분이 아닌 사이즈 값은 css.css에 있는 스타일로 변경하거나 기본값을 사용해줘
    - 태그의 class 가 길어지더라도 가능한 css 코드는 줄여줘
    - css 코드가 필수적인 부분은 가능한 태그내의 style=""로 변경해줘
    - 하나의 css 블럭보다는 여러개의 class 값으로 만들어줘
    - 가능하다면 <style> 태그의 내용은 50줄 이하로 줄여줘

1. 페이지 상단에 선택한 기간동안 점수가 어떻게 변해 왔는지, 기간동안 평균, 최고점수 등(이후 표시할 기록이 추가될 수 있음)을 표시하는 영역 생성
1. 점수는 동일한 일자에 진행한 게임별로 모아서 표시하고 게임을 진행한 경기장, 당일 평균, 당일 최고점수를 카드 형태로 표시한다.


## 2차 걔선
- 1차 개선 내용을 기반으로 2차 개선 내용을 작업한다.

### 기능
1. 회원은 한사람으로 고정이니 회원 선택하는 기능은 없어도 된다.

### 디자인
1. 조회 영역은 최소한으로 줄이거나 모달 형식으로 대체한다.
1. 개인 게임 기록을 등록하기 위한 모달을 제작한다.
1. 날짜별 기록 영역을 미리 확인할 수 있도록 목업 코드를 작성한다.
