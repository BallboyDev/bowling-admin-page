# EventScore.svelte 파일 수정 계획
- EventScore.svelte 파일은 볼링 동호회에서 진행한 그동안의 정기전 점수를 확인할 수 있는 페이지 이다.

## 1차 개선
- 수정된 내용은 동일한 경로의 EventScore_temp.svelte 파일로 복사(백업) 한후 적용

### 기능
1. 현재 구현된 기능은 모두 동일하게 구현
1. 기존 사용하는 API는 모두 그대로 사용
1. 추가적으로 필요하다고 생각되는 기능이 있다면 1차 수정후 정리하여 제안해줘

### 디자인
1. 모바일에서 시인성이 좋아지는 방향으로 개선을 진행한다.
1. 현재 프로젝트의 기본적인 색체는 유지한다.
1. 화면 디자인은 모바일 화면 기준을 우선시한다.
1. sveltestrap 라이브러리와 'front/template/css.css'코드를 기반으로 디자인을 하며 상세 내용은 아래를 따른다.
    - css 코드는 최소한으로 작성한다.
    - px단위가 필수가 아닌 부분은 rem 단위로 변환하고 가능한 0.25 단위로 변경해줘
    - 디자인에 필수적인 부분이 아닌 사이즈 값은 css.css에 있는 스타일로 변경하거나 기본값을 사용해줘
    - 태그의 class 가 길어지더라도 가능한 css 코드는 줄여줘
    - css 코드가 필수적인 부분은 가능한 태그내의 style=""로 변경해줘
    - 하나의 css 블럭보다는 여러개의 class 값으로 만들어줘
    - 가능하다면 <style> 태그의 내용은 50줄 이하로 줄여줘
