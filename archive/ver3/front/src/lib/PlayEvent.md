# PlayEvent.svelte 파일 수정 계획
- PlayEvent.svelte 파일은 볼링 동호회에서 정기전 진행 후 점수 기록과 기타 진행을 위한 페이지 이다.

## 1차 개선
- 수정된 내용은 동일한 경로의 PlayEvent_temp.svelte 파일로 복사(백업) 한후 적용

### 기능
1. 현재 구현된 기능은 모두 동일하게 구현
1. 기존 사용하는 API는 모두 그대로 사용
1. 추가적으로 필요하다고 생각되는 기능이 있다면 1차 수정 후 정리하여 제안해줘

### 디자인
1. 모바일에서 시인성이 좋아지는 방향으로 개선을 진행한다.
1. 현재 프로젝트의 기본적인 색체는 유지한다.
1. 화면 디자인은 모바일 화면 기준을 우선시한다.
1. sveltestrap 라이브러리와 'front/template/css.css'코드를 기반으로 디자인을 하며 상세 내용은 아래를 따른다.
    - css 코드는 최소한으로 작성한다.
    - px단위가 필수가 아닌 부분은 rem 단위로 변환하고 가능한 0.25 단위로 변경해줘
    - 디자인에 필수적인 부분이 아닌 사이즈 값은 css.css에 있는 스타일로 변경하거나 기본값을 사용해줘
    - 태그의 class 가 길어지더라도 가능한 css 코드는 줄여줘
    - css 코드가 필수적인 부분은 가능한 태그내의 style=""로 변경해줘
    - 하나의 css 블럭보다는 여러개의 class 값으로 만들어줘
    - 가능하다면 <style> 태그의 내용은 50줄 이하로 줄여줘

## 2차 걔선
- 1차 개선 내용을 기반으로 2차 개선 내용을 작업한다.
- 이후 수정은 PlayEvent.svelte에 바로 적용한다.

### 기능
1. 뽑기 기능을 구현하기 위한 모달을 제작해줘. 상세 내용은 아래를 따라줘
    - 뽑기는 해당 정기전에 참여한 인원들중 1인을 무작위로 선택하는 기능이야.
    - 중복 당첨등의 제한 사항은 우선 고려하지 않는다.
    - 뽑인 1인의 데이터는 기록 저장 API에 추가해주는데 backend는 수정하지 말고 callApi 함수만 수정해줘
1. 이름을 수정 할 수 있도록 기능을 추가해줘

### 디자인
1. public/gbc.png 이미지를 페이지에서 활용했으면 좋겠음.
1. 뽑기 버튼을 클릭하면 무작위로 선택된 1인을 표시해줘
    - 1인이 선택되면 꽃가루나 기타 효과를 통해 화려하게 표시가 되면 좋을것 같에
